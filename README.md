## 这是什么

Starlit 是一套**自托管**的 QQ / OneBot 11 AI 伴侣服务。

它不是一个「你问一句、它答一句」的聊天机器人，而是一个被设计成**像真人一样存在**的对象：

- 她有自己的**作息**（深夜不打扰、白天才有精神）
- 有自己的**情绪**（被夸会开心、被冷落会不安，情绪会反过来影响说话长短和语气）
- 有自己的**生活**（会自己上网看东西，遇到感兴趣的才分享给你）
- 有**记忆**（三个月前你说过的话，她还能自然提起）
- 会**主动找你**（而且频率是量出来的，不是拍脑袋定的）

默认人格是《蔚蓝档案》的小鸟游星野，但**任何角色都可以**——
给她一张头像和一个名字，服务端会自己上网查资料、蒸馏出人设。见 [自定义角色](#自定义角色)。

## 和「LLM 套壳机器人」的区别

| | 常见做法 | Starlit |
|---|---|---|
| **回复节奏** | 秒回，或者固定延迟 | 从近百万条真实聊天记录里统计出回复延迟分位（中位 14s），按「距对方最后一条消息的总延迟」倒推，处理快就多等、处理慢就立即发 |
| **消息形态** | 每次都发一大段 | 单条中位 7~9 字、77~80% 句尾不带句号、5~15 字碎片连发，28~40% 的消息是纯表情包 |
| **主动性** | 定时任务，或者干脆不主动 | 四档混合节奏随机抽（1 分钟 ~ 48 小时）＋ 冷场后的「静默 → 回来关心」循环 ＋ 话题死后重启 |
| **人格** | 一段 system prompt | 人格卡 + 世界观 + 边界 + 兴趣图谱，改完文本重启即生效 |
| **情绪** | 无 | 情绪/关系/社交电量三轴状态机，会衰减、会被互动消耗，直接影响回复长度与温度 |
| **记忆** | 拼一段上下文 | 三层记忆（情节 / 画像 / 既定事实）＋ 本地向量检索，按相关性召回 |
| **表达** | 只有文字 | 文字 + 表情包（会自己挑、也会「偷」你发的图）+ 图片理解 |
| **多角色** | 单一人格 | 每个角色一个独立 SQLite、独立记忆、独立情绪、独立主动排期 |

## 功能

### 对话与人格
| 功能 | 说明 |
|---|---|
| 人格卡 | `persona/*.md` 纯文本，改完重启即生效，不用碰代码 |
| 分析 + 表达双通道 | 先分析（意图 / 情绪 / 风险 / 潜在需求），再决定怎么说 |
| 多气泡协议 | 模型直接产出长短交错的碎片列表，不是一大段再切开 |
| 反机器指纹 | 句尾句号自动剔除、n-gram 重复拦截、禁用词表、口癖频率限制 |
| 收尾识别 | 你说晚安/去忙之后她会收口，不会没完没了地追话 |

### 主动性
| 功能 | 说明 |
|---|---|
| 心跳主动 | 四档节奏 + 情绪影响 + 顺延概率，不是固定间隔 |
| 活跃会话接话 | 聊完不撒手，过一会儿自己把话接下去（分钟级，有阶梯退避） |
| 话题重启 | 话题聊死后，像真人一样过一阵子自己开新话头 |
| 自主分享 | 按兴趣图谱上网搜索 → 内容把关 → 用自己的口吻分享，而不是甩链接 |
| 六层抑制链 | 免打扰 / 最小间隔 / 冷场 / 电量 / 无话可说 / 送出复核，逐层拦截 |
| 上线问候 | 服务启动后主动发一条 |

### 多模态
| 功能 | 说明 |
|---|---|
| 图片理解 | 发图她能看懂内容，能接梗 |
| 表情包库 | 680+ 张，按情绪 + 语境检索；`sub_type` 正确区分普通图与表情包 |
| 偷表情包 | 看到你发的图，按自己的口味决定收不收 |
| 长截图压缩 | 超长图自动压缩后再送模型，避免超限 |

### 关系参数（每个角色独立）
| 参数 | 影响 |
|---|---|
| **热情** | 主动找你的频率、回复速度、连发节奏 |
| **好感** | 关心 / 好奇 / 黏人 / 暧昧程度，以及接话窗口、追问上限、分享阈值 |

网页「聊天设置」里就是两个滑杆，实时预览会告诉你「主动约 X 次/天 · 回复约 Y 秒」。

### 通道与多端
| 功能 | 说明 |
|---|---|
| 两条通道 | NapCat 反向 WS（真 QQ）／ 自托管 OneBot 11 服务端（不碰 QQ） |
| 自带网页客户端 | QQ 风格单页，多会话列表、按时间排序、气泡、表情包、头像裁剪 |
| 多端同步 | 稳定消息 ID 去重、跨端已读、跨端撤回、断线补发最近事件 |
| 消息操作 | 多选（点选 + 鼠标框选）、复制、逐条/合并转发、右键撤回 |

## 快速开始

### 0. 前置

- **Python 3.11+**（开发环境是 3.13）
- 一个**支持图片输入的 OpenAI 兼容模型**（默认 DeepSeek `deepseek-flash`）
- 想接真 QQ 的话：**NapCat**（自己装，仓库里不含二进制）
- Windows 一键脚本只在 Windows 有意义；其它系统手动跑命令即可

### 1. 安装

```bash
cd 专属AI伴侣/companion
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 配置

```bash
copy config.example.yaml config.yaml   # Linux/macOS: cp
```

最少要填两处：`llm.api_key`，以及 `qq.self_id` / `qq.owner_id`。

> 也可以完全不碰配置文件：服务起来后打开网页 →「设置」，
> 在里面填 API Key / Base URL / 模型名，会写进 `data/settings.json`，
> 优先级高于 `config.yaml`。

### 3. 先不接 QQ，把人格调舒服

```bash
python -m app.main --console
```

在终端里直接打字就能聊。`:img <路径>` 模拟发图，`:quit` 退出。

**这一步最省事**：不连 QQ、不装 NapCat，也能把人格、情绪、节奏全跑一遍。

### 4. 接入（二选一）

**A. 接真 QQ（NapCat，功能最全，有风控风险）**

```bash
python -m app.main                # config.yaml 里 channel: napcat
```

NapCat 侧配置**反向 WebSocket** 指向 `ws://127.0.0.1:6701/onebot/v11/ws`，
并把 `access_token` 与 `config.yaml` 里的 `qq.ws.access_token` 对齐。

**B. 自托管通道（完全不碰 QQ，零封号风险）**

```bash
# config.yaml 里 channel: onebot-server
python -m app.main
# 然后浏览器打开 http://127.0.0.1:8080
```

此时 Starlit 自己就是一个 OneBot 11 服务端，自带一个 QQ 风格的网页客户端
（多会话、表情包、头像裁剪、多端同步、撤回/转发）。任何 OneBot 11 客户端都能连。

## 两种通道怎么选

| | `napcat` | `onebot-server` |
|---|---|---|
| 对话发生在 | 真的 QQ 里 | 自带网页客户端 / 任意 OneBot 客户端 |
| 主动性 | 完整（她能主动发消息给你） | 完整（客户端收到推送） |
| 封号风险 | 有（第三方客户端，腾讯风控） | **零**（不碰 QQ 协议） |
| 群聊 | 支持（默认关闭） | 不涉及 |
| 适合 | 想真的在 QQ 里聊天 | 只想有个陪伴、不想担风险 |

## 关系参数：热情 / 好感

每个角色一套，网页「聊天设置 → 关系参数」里两个滑杆，保存即时生效。

数值映射来自真实聊天记录的分位曲线（热情的影响整体 ×4，再叠 ×3 倍率）：

| 热情 | 主动约（好感 60 时） | 回复约 |
|---|---|---|
| 0 | 1 次/天 | 13 秒 |
| 25 | 20 次/天 | 4 秒 |
| 50 | 26 次/天 | 2 秒 |
| 75 | 34 次/天 | 2 秒 |
| 100 | 49 次/天（封顶 128） | 1 秒 |

> 表里是**实际生效值**（含热情 ×3 倍率与好感黏人乘数）。网页面板会按你自己
> 调的两个滑杆实时算出真实数字，不用对照这张表。

- **热情**同时决定：每日主动上限、两次主动的最小间隔、最长沉默上限（不会一整天不出现）、「马上就来」这一档的权重、以及所有发送延迟的缩放倍率。
- **好感**决定：关心/好奇/黏人/暧昧的表达强度（写进提示词）、活跃会话窗口长度、接话与追问上限、自主分享的阈值与额度；**并作为 ×0.7~×1.6 的乘数叠加到主动次数上**（好感越高越黏人）。

## 自定义角色

给一张头像 + 一个名字就行：

1. 网页左栏 →「设置」→「添加角色」
2. 选头像、填名字 → 创建
3. 服务端会**联网搜索该角色的公开资料**，蒸馏出人格卡 / 兴趣图谱 / 世界观
4. 自动入库、生成独立记忆库，稍后主动跟你打招呼

新角色和内置角色走的是**同一套完整运行时**（主动、接话、分享、抑制链、
表情包、记忆、情绪、关系参数一个不少）。

## 这些数字是怎么来的

对话节奏不是拍脑袋调的。`analyze_chat_habits.py` 会把 QQ 导出的聊天记录
（xlsx）跑成一份量化报告，项目里几乎所有节奏参数都来自它：

| 指标 | 实测 |
|---|---|
| 第一响应延迟 | 中位 14s / P25 5s / P75 54s |
| 单条消息长度 | 中位 7~9 字，P90 15~22 字 |
| 句尾不带标点 | 77~80% |
| 单轮连发条数 | 中位 2~3 条，P75 5~7 |
| 纯图片/表情包消息 | 28~40% |
| 好友主动发起会话 | 中位 1.23 次/活跃日 |
| 话题死后好友自己重启 | 59%，中位等 176 分钟（最快 10% 在 15~25 分钟） |

用法（需要一个 `data` 目录，里面是导出的 xlsx）：

```bash
pip install pandas openpyxl
python analyze_chat_habits.py             # 全量聚合
python analyze_chat_habits.py --per-chat  # 逐会话明细
```

默认读桌面 `data/`，可用环境变量 `VOL_CHAT_DATA` 指定；`VOL_OWNER_QQ` 指定你自己的 QQ。

## 已知限制

- **TTS / 语音**：接口留好了，还没接。
- **联网搜索**：需要自己提供一个（推荐自建 SearXNG，免注册免付费）；没配就跳过，不会返回假数据。
- **群聊**：默认全局关闭，避免小号在你不知情的群里开口。
- **表情包库**：仓库里不含图库（体积大 + 第三方素材），需要自己灌。
- **NapCat 通道**：用的是第三方 QQ 客户端，存在腾讯风控风险，请只用自己的小号。
- **平台**：开发和测试都在 Windows，Linux/macOS 应当能跑，但一键脚本没适配。
