## 它会不会在群里乱说话？—— 不会，已经关死了

启动时你会看到这三行：

```
[policy] 群聊响应：off —— 关闭（任何群消息都不回）
[policy] 私聊：只回 10002，其他人一律不理
[policy] 主动消息：只发给主人的私聊，任何时候都不会发到群里
```

具体保证：

| 场景 | 行为 |
|---|---|
| 学校群里有人 @ 它 | **不回**（`group_mode: off`，被 @ 也不开口） |
| 群里随便聊天 | **不回** |
| 同学私聊它 | **不回**（只认 10002） |
| 它主动找你 | 只发到你私聊，**代码里根本没有群 ID 参数** |
| 它自己学到东西想分享 | 同上，只发你私聊 |

以后想让它在你指定的某个群里能被 @ 出来，改 `config.yaml`：

```yaml
group_mode: "allowlist"
group_allowlist: ["你要放行的群号"]
```

⚠️ 但要注意：`mention` 模式下**群里任何成员 @ 它都能让它开口**，
在你那个有同学的号上不建议开。

## 然后就能用了

拿你自己的 QQ（10002）给小号（10001）发一条消息。

**预期**：小号会回你，语气是短句、口语化的，不回你「作为AI」这种话。

**再发一张表情包**，它应该能说出图里是什么。

### 几个调试指令（私聊里发）

| 发什么 | 它会做什么 |
|---|---|
| `/state` | 显示它当前的情绪数值和跟你的关系数值 |
| `/why` | 解释上一轮它为什么这么回 |
| `/poke` | 手动触发一次「主动找你」，看六层抑制链逐层判断结果 |
| `/mood 低落` | 手动把它的心情改成低落（用来测情绪有没有真的影响语气） |

### 看它的「心理体检报告」

在命令行里跑（**服务可以不停**，读的是同一个数据库）：

```
cd vol\专属AI伴侣\companion
.venv\Scripts\python.exe -m scripts.checkup
```

会打印：情绪数值、关系数值、它记住的你的偏好、长期记忆、兴趣图谱、
最近对话、主动性计数与**下一次主动消息的排期**、表情包库规模。

**这是判断「感性部分是不是真在工作」的唯一方式** —— 光看它回话看不出，
要看效价 / 孤独度这些数值有没有跟着你的话动。

> 注：这个脚本以前叫 `inspect.py`，因为跟标准库的 `inspect` 撞名，
> 会让 `python scripts/preflight.py` 直接崩（`asyncio` 依赖它）。
> 已改名 `checkup.py`，并给所有脚本加了 sys.path 防御。
