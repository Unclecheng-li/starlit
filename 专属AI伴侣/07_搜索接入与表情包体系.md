**装的什么、放哪儿**

```

├─ src\            官方仓库（git clone 的，SearXNG 不在 PyPI 上）
├─ settings.yml    配置（关键：search.formats 含 json）
├─ system-ca.pem   从 Windows 根证书导出的 CA 包
└─ searx.log       运行日志
```

配置已写进 `companion/config.yaml`：

```yaml

  provider: "searx"
  endpoint: "http://127.0.0.1:8888"
```

**启动**：双击 `vol\start_searxng.bat`

**只启用国内可达的引擎**：bing / baidu / 360search / quark / sogou / mojeek
（默认那套是 brave / duckduckgo / google，从国内基本连不上，所以我在 settings.yml 里
用 `use_default_settings.engines.keep_only` 把它们裁掉了）

### 过程中踩的 4 个坑（都解决了，记下来免得重踩）

1. **`pip install searxng` 装到的是个 MCP 包装器**，不是搜索引擎本体。SearXNG 官方不在 PyPI 发布，
   得 `git clone`。
2. **`git clone` 检出失败**：仓库里有 4 个文件名带冒号（`searxng.conf:socket`），
   Windows 文件系统不允许。这 4 个是部署模板，用 `git checkout -f -- . ':(exclude)utils/templates/etc'`
   跳过即可。
3. **`setup.py` 有个先有鸡后有蛋的问题**：读版本号时要 `import msgspec`，但那时依赖还没装。
   解法：先 `pip install -r requirements.txt`，再装本体。
4. **★ 最关键的一个：所有引擎都报 `SSL error: certificate validation has failed`**
   —— 连百度都失败。查明是 SearXNG 用的 `curl_cffi` **不认本机的根证书**。
   解法：把 Windows 系统根证书导出成 PEM（`system-ca.pem`），用 `CURL_CA_BUNDLE` 指给它。
   `start_searxng.bat` 里已经设好了。

另外还打了个小补丁：`searx/valkeydb.py` 里 `import pwd`（Unix 专有模块）改成条件导入 ——
那段只在配了 Redis 时才用，Windows 上直接跳过。

## 三、偷表情包（新功能）

你发一张图，它会按**自己的口味**决定收不收。

### 三层过滤（省钱也省事）

```
① 本地硬门槛：开关 → 每日上限 → 内容去重（MD5）
② 掷骰子：steal_probability（默认 55%）
③ 只有过了前两层，才去问模型「喜不喜欢」
```

### 它的口味（写在 prompt 里）

**收**：好笑的、搞怪卖萌的、无语/崩溃类、海洋或鲸鱼相关、Blue Archive 相关、猫猫狗狗小鸟
**不收**：太糊的、纯文字截图、露骨或血腥过头的、别人隐私的、单纯风景照或商品图、无聊的

### 实测

```
判定: keep=True emotion=卖萌
reason=绿毛阳奈爱心眼举铃铛，Blue Archive 加卖萌搞怪，这不上我收藏夹我收藏夹都得抗议。
[steal] 收下了：卖萌_03847545.gif
图库: 680 -> 681
重复再收: keep=False reason=这张已经有了
```

理由很有人味，而且**重复收会被去重拦下**。

### 收下的图去哪了

```
data\stickers\stolen\卖萌_03847545.gif
```

文件名带情绪前缀 —— 下次用 `scripts/ingest_stickers.py` 重建索引时，
它会被**文件名模式**自动解析到，不用调模型。

### 它还会顺口告诉你一句

收下之后，回复里会自然带一句「这张大叔收下了」之类的话（不是硬插，是给表达通道的一个提示）。

### 配额

| 项 | 默认 | 说明 |
|---|---|---|
| `steal_probability` | 0.55 | 过了本地门槛后，收下的概率 |
| `steal_daily_max` | 8 | 每天最多收几张（**落盘时计数**） |
| `steal_from_groups` | false | 群里别人发的图**默认不收** |

## 四、发图的频率：跟内容/心情挂钩

不是「能发就发」，是让发图这件事**有节奏**：

```
最终概率 = 基础概率(0.55)
         × (0.6 + 0.8 × 情绪强度)      ← 情绪越强越可能发
         × 心情系数                      ← 心情极差 ×0.25，心情好 ×1.25
         × 电量系数                      ← 电量低 ×0.3
         × 中性系数                      ← 中性情绪 ×0.4（平淡闲聊不必配图）
```

外加：**冷却 20 分钟**、**每日上限 20 张**、**上一条刚发过图就直接跳过**。

日志会写清楚这一轮为什么发/不发：

```
[main] 不发表情包：未命中（概率 6%，掷 0.59）
[main] 发表情包：害羞_A1FF3439.gif（情绪 害羞｜命中（概率 72%，掷 0.31）｜日常接梗）
```

> 顺便：原来默认值太保守（实测掷出 6%，几乎不发），这轮把
> `base_probability` 提到 0.55、电量阈值从 40 降到 30、冷却从 25 分钟降到 20 分钟。

## 五、主体性：多说「我」

在 `persona.md` 里新增了一节「表达欲」，并写进了表达通道的 system prompt：

- **先给自己的反应，再给内容** —— 不要一上来就顺着对方接话
- **常说「我觉得 / 大叔我 / 我不这么看 / 我更喜欢……」**
- **可以说自己正在干什么**：「刚巡逻回来」「刚被芹香念了一顿」
- **可以主动岔开到自己的话题**
- **可以有明确的喜欢和不喜欢**
- **可以拒绝、反驳、觉得无聊**，不必每句都附和
- 明令禁止客服腔：「我理解你的意思。你说的这件事，可以从几个方面来看……」

实测效果：

```
你 > 今天好累啊，感觉什么都不想干

🤖 呜嘿~
🤖 那正好，今天谁都别干正事
🤖 大叔也是，睡到下午才爬起来，被芹香念了两遍，念完我又躺回去了
🤖 累了就瘫着呗，反正事情又不会长腿跑掉
```

（对话中途插入了「算了不说了，先睡」，**她真的把话接下去并自己收了尾**，而不是等回复。）

## 七、QQ 表情还是收不到 —— 需要你配合一次

我在代码里加了**失败即落盘**的诊断：图取不到时，NapCat 发来的原始段结构会写进

```
companion\data\failed_media.jsonl
```

**请你发一次那个表情包**，然后把日志里这两行发我：

```
[channel] 媒体段结构：...
[main] 该消息有图段但解析不出图源，原始结构已写入 ...
```

或者直接把 `data\failed_media.jsonl` 的内容贴给我。

有了原始结构我就能确定是哪种情况：
- 是 `mface`（QQ 商城表情）→ 协议里**压根不带图片数据**，只能想办法从别处取
- 是 `image` 段但 NapCat 没给 `base64`/本地路径/URL → 改 NapCat 配置
- 是给了 URL 但取不到 → 换下载方式

已经确认过的：`onebot11_10001.json` 里 `enableLocalFile2Url: true` 是开着的，
反向 WS 和 HTTP 也都正常，所以**不是配置没生效**。
