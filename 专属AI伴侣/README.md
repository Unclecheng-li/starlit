# 专属 AI 伴侣 · 项目目录

## 平时就用这两个

```
vol\一键启动.bat      按顺序起：搜索实例 → 伴侣服务 → QQ 通道（已在跑的自动跳过）
                      没登录的话会自动弹二维码窗口
vol\一键停止.bat      只停搜索和伴侣，不动 NapCat / QQ
```

单独重启某一个：`start_searxng.bat` / `start_companion.bat` / `start_napcat.bat`
二维码过期了要重新弹：`扫码登录.bat`
识图诊断：控制台会直接打印，失败的图另存 `companion/data/failed_media.jsonl`
改过配置后自检：`preflight.bat`

## 已确认的技术决策

| 项 | 决定 |
|---|---|
| 模型 | DeepSeek V4.1-Flash，**API 模型名写 `deepseek-flash`**（自带识图） |
| 部署 | 云 API |
| QQ 通道 | QQ 小号 → NapCat + OneBot 11 反向 WebSocket（全功能，主动消息不受官方限制） |
| 语言 | Python 3.13 |

⚠️ 两个必须记住的坑：
- `deepseek-v4-pro` 是**纯文本**模型，不能用来识图；识图也走 `deepseek-flash`
- NapCat 发图片时 **`sub_type=1` 才是表情包**，`0` 是普通图

## 快速开始

**环境已经装好了**（NapCat + 便携 QQ + 依赖 + 配置），只剩 3 项需要你本人操作。

```bash
# 1. 自检（会真的测一次识图）
vol\preflight.bat

# 2. 填 companion/config.yaml 的 llm.api_key 和两个 QQ 号
# 3. 启动伴侣服务
vol\start_companion.bat
# 4. 启动 NapCat 并扫码登录小号（会弹 UAC）
vol\start_napcat.bat
```

详见 `03_安装与启动.md`。

### 不装 NapCat 也能先试

```bash
cd companion
.venv\Scripts\python.exe -m app.main --console
```

控制台里直接打字就能聊，`:img <路径>` 模拟发图。**调人设和情绪在这一步做最省事。**
