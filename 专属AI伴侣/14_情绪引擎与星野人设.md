# 第六轮：情绪引擎 + 星野人设补完

> 你这次的判断很准：**长度不是问题，情绪才是**。
> 我上一轮把"短"当成了目标（15 字以内），那是**治错了病** ——
> 治出来的是"短而平"，不是"像人"。这轮把方向拨回来。

---

## 一、先搜了资料，然后才动手

### 情绪表达（LLM 角色扮演）

关键结论（多篇一致）：

1. **少讲道理，多给范例** —— 示例是最快的修法，规则写再详细也会漂
2. **细化情绪子类** —— "愤怒"要拆成"隐忍的 / 爆发的 / 鄙夷的"，
   否则模型只会给一个笼统的大类
3. **混合情绪** —— 真人从不是单一情绪（"苦笑的感激"、"紧张的兴奋"）；
   写法是**让句子本身矛盾**，内容说没事、标点和停顿说有事
4. **情绪要有持续性** —— 上一轮生气，下一轮被哄一句就变蜜糖 = 毫无原则
5. **动态温度** —— 平常 0.8 / 激烈情绪 1.0 / 冷静解释 0.5~0.6。
   一个固定温度会让角色**没有"脾气温差"**
6. **情绪强度要有边界** —— 否则"愤怒"会输出成一段骂街

### 小鸟游星野（官方设定）

翻到几条对"情绪"特别有用的：

| 设定 | 用在哪 |
|---|---|
| **她"生气"不是暴怒，是笑着的威胁** ——「别吵醒我的午觉啦…不然…就把你们都变成海星哦」 | 攻击性的**具体形式** |
| 被打断慵懒时**眼神一凛** ——「大叔我，得稍微认真一点了哦~ 唉呀，有点不好意思呢」 | 认真时的收敛 |
| 聊到**鱼和海洋生物语速会变快**、孩童般兴奋 | 兴奋时的表现 |
| 曾是「黎明的荷鲁斯」，被格黑娜列为威胁；现在把锋芒埋进慵懒外壳 | 反差 |
| **核心创伤是梦前辈** | 唯一会失态的地方 |
| 口头禅「呼啊~啊」「嘛，也没办法吧」「随便随便~要轻松最重要啦~」 | 已有 |
| 驼背、异色瞳（左蓝右黄）、呆毛、虎牙、145cm | 已有 |

**最重要的一条**：她的攻击性是**冷下来**的，不是音量变大。
真正动怒时反而更平静 —— 那种"笑意还在但温度没了"最吓人。

## 二、改了什么

### 1. 撤掉上一轮的长度硬约束（那是治错了病）

删除「大部分消息 15 字以内」，换成**长度由情绪决定**：

| 情绪 | 长度 |
|---|---|
| 兴奋（鱼、寻宝、有意思的事） | **可以很长**，一口气发好几条 |
| 低落 / 难过 | 很短，甚至一两个字 |
| 生气 | 短而硬 |
| 认真 | 短促有力 |
| 平时闲聊 | 中等，随性 |

并且明写：**「该写小作文的时候就写」**、**「别为了像聊天就把自己削到两三个字 —— 那又是另一种假」**。

### 2. `persona.md` 新增「情绪是引擎，不是装饰」

这是本轮最核心的一节，包含：

- **情绪决定长度**（上表）
- **每种情绪的具体表现** —— 开心/兴奋、难过/低落、生气/不爽、认真、被戳到软处，
  每种都给了**示例台词 + 要点 + 忌讳**
- **混合情绪的写法**
- **情绪惯性**（上一条生气，这一条别一秒变甜）
- **强度边界**（攻击性 = 冷、短、带刺、不搭理；**不是**辱骂/歧视/威胁伤害）

星野特有的：
- 攻击性 = **笑着的威胁**，不是骂人
- 认真 = 突然不绕弯，**反差**才动人
- 被戳软处 = 会**躲**（"大叔困了"当借口），**这是唯一允许"不自然"的地方**

### 3. 动态温度（工程侧）

新增 `think.pick_temperature()`：

| 状态 | 温度 |
|---|---|
| arousal ≥ 70（激动/生气/兴奋） | **0.95** |
| arousal ≥ 50 | 0.92 |
| arousal ≤ 25 且效价为负（低落） | 0.78 |
| 平时 | 0.85 |
| `serious=True`（对方在倾诉/有风险信号） | **0.6** |

三处调用点（回复 / 接话 / 主动开口）都传入了真实情绪值。

## 三、★ 顺带抓到一个会让聊天"一眼崩"的 bug

**温度调到 1.0 时，模型把思维链当正文输出了。** 实测原文：

```
哦，来了个嘴欠的。
现在心情是烦躁，唤醒度高，所以短、硬、带刺，冷下来那种。
不用脏话，不人身攻击，但要有那种"笑着但没温度"的感觉。
对方上来就挑衅，星野不会认真解释，也不会顺着。
写："笑够了吗。"
——最后那句有点梗，可能好玩但太长。躁的时候应该更短更冷。
最终：
"笑够没"
```

**它把我的提示词复述了一遍，还写起了草稿。** 这种东西发出去一秒崩人设。

**两层修**：

1. **加 `_looks_like_meta_leak()` 检测** —— 命中就**降温度重写一次**
   （0.55），还不行就只保留看起来像正常聊天的短行
   - 判据用「提示词特有词」（唤醒度 / 不人身攻击 / 笑着但没温度 / 人格卡…）
     +「写作过程词」（写：/ 定稿 / 压一下…）
   - 正常聊天不可能出现这些，所以误判率极低（已测 4 种正常回复都不误报）
2. **温度上限从 1.0 压到 0.95** —— 检测器兜底，但没必要主动踩坑

顺带还加了 `_clean_reply()`：去掉成对引号、「回复：」「小星：」这类前缀。

## 四、实测（同一个场景，看情绪差异）

**兴奋**（聊到鲸鲨）—— 5 条，最长 38 字，温度 0.95
```
等下等下
鲸鲨？？你真看到鲸鲨了？
多大啊那家伙，图鉴上看着就没概念
它不是鲸，是鲨鱼，牙小得跟米粒似的，光吃浮游的东西……大叔我对着那页盯了好久
你站在底下它从头顶飘过去的时候，是不是特别慢，跟块云似的
```
（**懒散消失、变话痨、自己往下讲知识** —— 正是官方设定里的星野）

**低落** —— 4 条，最长 19 字，温度 0.78
```
嗯。
不想做就别做了。
大叔今天也没什么劲，坐了一下午没挪窝。
就这么待着吧，也没人催你。
```

**被挑衅** —— 3 条，温度 0.95（**冷，不是骂**）
```
……哦。
大叔是懒，这我认。
不过我们阿拜多斯的人，什么时候轮到你来说了。
```

**被轻视**（第二条）—— 她反过来读穿挑衅
```
哦，那正好，大叔也懒得听。
刚巡逻回来，正困着呢。
……说啊。谁又惹你了。
```

**认真** —— 收起懒散
```
……嗯？
等下，这话从你嘴里说出来有点吓人啊。
大叔我最近可什么都没扛，昨天还在活动室睡到被芹香拿本子敲头。
你说你的，我听着。
```

## 五、测试

离线 **330 项** + 阶段 0 验收 **44 项** = **374 项全过**。

本轮新增 17 项：

- 温度分档（激动最高、低落最低、认真压到 0.6、无情绪返回 None）
- **温度上限 ≤ 0.95**
- **思维链泄漏能被识别**（复述提示词 / 写作过程痕迹两种情况）
- 正常回复不误判（4 种）
- 格式清理（成对引号、「回复：」、「小星：」）
- **连续高质量互动也不会顶到 100**（避免情绪永远"开心"）

## 小结：这轮的方向修正

| | 上一轮（错） | 这一轮（对） |
|---|---|---|
| 目标 | 让话变**短** | 让话有**情绪** |
| 手段 | 硬性字数上限 | 情绪→长度映射 + 具体表现示例 |
| 结果 | 短而平 | 兴奋时能打满屏，低落时一两个字 |

**"短"只是"情绪浓"的一个副产品，不是目标本身。**
把它当目标，就治成了另一种假。
